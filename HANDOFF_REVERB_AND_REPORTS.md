## 6. Key design decisions the next agent must not undo

1. Reverb is exposed under `/reverb-websocket` on the existing domain, not a new subdomain.
2. Apache uses `mod_proxy_wstunnel` with `ProxyPass`/`ProxyPassReverse` + `ProxyPreserveHost On`. Rewrite rules do not work for this path because of `.htaccess` front-controller rules.
3. Browser Echo client must set `wsPath: '/reverb-websocket'`; default root path fails.
4. Frontend listens on the `reports.{userId}` private channel for `.report.completed`, not `App.Models.User.{id}` (Livewire echo mapping struggles with dots).
5. The job broadcasts with `->toOthers()` and is wrapped in try/catch so queue jobs never fail because Reverb is down.
6. `wire:poll.5s` is the fallback when websockets are unavailable.
7. The user-id meta tag must be pushed into `@push('head')`; body-level meta is too late for Echo init.
